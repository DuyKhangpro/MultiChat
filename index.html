API Key

Key được mã hóa AES-GCM trước khi lưu vào trình duyệt, tự lưu khi bạn nhập nên F5 không bị mất. Đây là mã hóa phía trình duyệt, không thay thế việc giữ máy và trình duyệt của bạn an toàn.

Trình duyệt đang chặn lưu hoặc mã hóa dữ liệu nên key sẽ mất khi F5. Hãy mở file trực tiếp bằng Chrome, Edge hoặc Firefox (không mở trong cửa sổ xem trước).

Thông báo

Trình duyệt không cấp quyền thông báo. Hãy cho phép thông báo cho trang này trong cài đặt trình duyệt. Nếu bạn mở file trực tiếp (file://), Chrome thường chặn thông báo; khi đó hãy chạy qua máy chủ cục bộ như http://localhost.
